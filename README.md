# SecondLook

Code for **Hindsight Is 20/20: Post-Hoc Self-Verification of Radiology Reports Generated by Large Vision-Language Models**

SecondLook checks each finding in a generated report with three signals from the same model and deletes the ones it judges unsupported:

- **Track record**: how often the model's claims of this finding type were correct on a small labelled calibration set
- **Re-check**: the model's yes/no answer when asked about the finding again, with only the image
- **Uncertainty**: the model's token entropy while writing the finding

A logistic regression fitted on the calibration set combines the three signals, and claims below a calibrated threshold are removed. SecondLook needs no training of the model, no extra model and no extra generations.

## Setup

```bash
pip install -r requirements.txt
export HF_TOKEN=<your Hugging Face token>   # MedGemma is gated; accept its license on Hugging Face first
```

All commands are run from the repository root. Outputs go to `results/`.

## Data

- **IU-Xray** is downloaded automatically from Hugging Face (`X-iZhang/IU-Xray-RRG`). The calibration and test splits are in `splits/iu_xray_split.json`.
- **CheXpert Plus** must be obtained from the [Stanford AIMI](https://aimi.stanford.edu/datasets/chexpert-plus) website under its data use agreement and is not redistributed here. `src/chexpert_data.py` expects `data/chexpert/chexpert_subset.jsonl` (or set `CHEXPERT_DIR`), with one study per line: `{"id": ..., "image_path": ..., "findings": ...}`. `splits/chexpert_split.json` indexes the rows of that file. The list of study IDs is available on request.

## Pipeline (IU-Xray, MedGemma)

```bash
# 1. generate reports (calibration and test splits)
python src/generate.py --split_file splits/iu_xray_split.json --split_name cal
python src/generate.py --split_file splits/iu_xray_split.json --split_name test

# 2. compute the re-check and uncertainty signals
python src/signals.py --mode calibrate --tag greedy --preds results/greedy_findings_p1_cal.jsonl \
    --split_file splits/iu_xray_split.json --split_name cal
python src/signals.py --mode apply --tag greedy --preds results/greedy_findings_p1_test.jsonl \
    --split_file splits/iu_xray_split.json --split_name test

# 3. fit SecondLook on calibration and edit the test reports
python src/secondlook.py --cal_rows results/verify_greedy_cal_rows.jsonl \
    --test results/greedy_verified_p1_test.jsonl

# 4. evaluate and test significance
python src/evaluate.py --dataset iu_xray --split_file splits/iu_xray_split.json
python src/significance.py --per_sample results/scores_test_per_sample.json
```

Options:

- **CheXpert Plus**: add `--dataset chexpert` to `generate.py`, `signals.py` and `evaluate.py`, use `splits/chexpert_split.json`, and write to a separate folder (`--out` / `--results`).
- **Other models**: add `--backbone llavamed` or `--backbone chexagent` to `generate.py` and `signals.py`.
- **Signal ablation**: `secondlook.py --features prior` (track record only), `prior,yesno`, etc.
- **Other decoders**: `secondlook.py` and `evaluate.py` accept the outputs of any decoder in the same JSONL format (`id`, `prediction`, `ground_truth`). Our VCD, DoLa, OPERA and CCD implementations are available on request.

## Files

| File | Purpose |
|---|---|
| `src/models.py` | MedGemma, LLaVA-Med and CheXagent adapters; greedy decoding |
| `src/generate.py` | Report generation |
| `src/claims.py` | Finding extraction (19 types), negation handling, clause-level deletion |
| `src/signals.py` | Re-check (with blank-image bias filter) and uncertainty per claim |
| `src/secondlook.py` | Track record, logistic combination, threshold and report editing |
| `src/evaluate.py` | RadGraph finding-level metrics and CheXbert / RadEval scores |
| `src/finding_metrics.py` | Finding-level precision, recall, F1 and unsupported-finding rate |
| `src/significance.py` | Paired bootstrap tests |
| `src/iu_xray_data.py`, `src/chexpert_data.py` | Dataset loaders |
